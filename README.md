# SideNote Analytics

The website for SideNote Analytics, a Chrome side panel that shows Google
Analytics 4 numbers for the page you are on.

- `index.html`: the landing page
- `privacy.html`: the privacy policy
- `support.html`: the support page
- `guides/`: GA4 how-to guides, drafted with AI and reviewed before
  publishing. See `docs/seo-engine/README.md`.

Static files served by GitHub Pages. The panel screenshots use invented
example data.
